# Story 3.4: 분류 취소 및 완료 피드백

Status: review

## Story

채매니저로서,
분류 도중 잘못 시작했다고 깨달으면 취소할 수 있고, 분류가 완료됐을 때 명확한 완료 신호를 받고 싶다,
그래야 실수를 바로잡을 수 있고 결과 화면으로 자신 있게 넘어갈 수 있다.

## Acceptance Criteria

1. **[취소 확인]** 분류 진행 중 "분류 취소" 버튼을 클릭하면 "분류를 취소하시겠습니까? 지금까지의 결과는 저장되지 않습니다." 확인 팝업이 표시된다. (FR39)
2. **[취소 처리]** 취소 확인 시 해당 세션이 `cancelled` 상태로 업데이트되고 `/upload` 화면으로 이동한다. (FR39)
3. **[완료 피드백]** 모든 분류와 인사이트 요약이 완료되면 "N건 분류 완료!" 메시지가 1초간 표시된다. (FR40)
4. **[결과 화면 이동]** 완료 메시지 이후 fade 전환(150ms)으로 `/result` 페이지로 이동한다. (FR40, UX-DR15)
5. **[결과 데이터 로드 준비]** `/result` 페이지 진입 시 세션이 유지되고 결과 데이터 조회 API가 준비되어 있다. (FR36)

## Dev Notes

### 이전 Story에서 이어받는 맥락

- Story 3.1의 `/analyzing` 화면은 배치 진행 상태를 표시한다.
- Story 3.2는 `/api/classify`로 결과를 저장한다.
- Story 3.3은 `/api/insight` 호출 시 `sessions.status = completed`로 업데이트한다.

### 이번 Story의 핵심 제약

- 취소는 서버 Route Handler를 통해 `sessions.status = cancelled`로 저장한다.
- 취소 시 브라우저에 남은 `session_id`, `classification_draft`를 정리한다.
- 완료 전환은 디자인 시스템 요구대로 fade 150ms만 사용한다.
- 결과 화면 데이터는 Epic 4에서 본격 UI가 완성되지만, Epic 3 완료 기준으로 조회 API는 준비한다.
