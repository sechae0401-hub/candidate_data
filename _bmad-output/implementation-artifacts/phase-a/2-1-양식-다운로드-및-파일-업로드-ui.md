# Story 2.1: 양식 다운로드 및 파일 업로드 UI

Status: review

## Story

채매니저로서,
분석용 엑셀 양식을 다운로드하고 데이터를 채운 파일을 드래그앤드롭 또는 클릭으로 업로드할 수 있고 싶다,
그래야 어떻게 시작해야 하는지 즉시 알고 파일을 빠르게 제출할 수 있다.

## Acceptance Criteria

1. **[온보딩 Empty State]** `/upload` 첫 방문 시 "①양식 다운로드 → ②데이터 입력 → ③파일 업로드" 3단계 안내가 표시된다. (FR38, UX-DR5)
2. **[양식 다운로드]** 화면 상단에 "분석용 엑셀 양식 다운로드" 버튼이 항상 표시되고, 클릭 시 고정 양식 파일이 다운로드된다. (FR1)
3. **[드래그앤드롭 업로드]** xlsx/xls 파일을 드롭하면 파일명과 총 행 수가 표시된다. (FR2)
4. **[클릭 업로드]** 파일 선택으로 xlsx/xls 파일을 고르면 동일하게 파일명과 총 행 수가 표시된다. (FR2)
5. **[형식 제한]** xlsx/xls 외 형식은 거부되고 "xlsx 또는 xls 파일만 업로드할 수 있습니다" 에러 메시지가 표시된다. (FR3)

## Dev Notes

### 이전 Story에서 이어받는 맥락

- Story 1.3에서 `/upload`는 시작점 역할의 골격과 공통 네비게이션 바까지 준비되어 있다.
- `src/upload/` 모듈 디렉터리는 비어 있으므로 이번 Story부터 업로드 전용 로직을 이곳에 배치한다.
- `public/templates/.gitkeep`만 존재하고 실제 양식 파일은 아직 없다.

### 이번 Story의 핵심 제약

- SheetJS는 브라우저에서만 동적 import 해야 한다. 정적 import는 금지한다.
- 파일은 서버로 전송하지 않고 브라우저 메모리에서 읽어 총 행 수와 컬럼 구조를 파악한다.
- 보안 규칙상 허용 확장자는 `.xlsx`, `.xls`, 최대 10MB다.
- 이후 Story 2.2~2.4에서 재사용할 수 있도록 업로드 결과 모델은 모듈 유틸로 분리한다.
