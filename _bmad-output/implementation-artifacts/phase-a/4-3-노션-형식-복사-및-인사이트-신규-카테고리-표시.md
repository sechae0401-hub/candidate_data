# Story 4.3: 노션 형식 복사 및 인사이트·신규 카테고리 표시

Status: review

## Story

채매니저로서,
모든 검토 필요 항목을 완료 처리한 후 분류 결과와 인사이트 요약을 노션에 바로 붙여넣을 수 있는 마크다운으로 복사하고 싶다,
그래야 별도 포맷 작업 없이 팀 문서에 공유할 수 있다.

## Acceptance Criteria

1. **[복사 버튼 비활성]** 검토 필요 행이 1건 이상 남아있으면 "노션 형식 복사" 버튼이 비활성 상태로 표시된다. (FR32, UX-DR7)
2. **[복사 버튼 활성]** 모든 검토 필요 행이 완료 처리되면 "노션 형식 복사" 버튼이 Primary 활성 스타일로 전환된다. (FR32, UX-DR7)
3. **[노션 마크다운 복사]** 복사 버튼 클릭 시 분류 결과 마크다운 테이블과 인사이트 요약 단락이 클립보드에 복사되고 "복사되었습니다" 토스트가 표시된다. (FR33)
4. **[클립보드 fallback]** `navigator.clipboard.writeText`가 실패하면 `document.execCommand("copy")` fallback을 시도하고, 둘 다 실패하면 HTTPS 환경 안내 토스트를 표시한다.
5. **[신규 카테고리 표시]** 신규 카테고리가 있으면 "이번 분류에서 새로 만들어진 카테고리: OOO (3건), XXX (1건)" 형태로 표시된다. (FR34)
6. **[인사이트 표시]** 인사이트 카드에 "참고용" 안내와 함께 인사이트 요약, 운영 추천 액션, 이전 기수 비교 섹션을 표시한다. (FR24, FR41, FR42, UX-DR8)

## Dev Notes

### 이전 Story에서 이어받는 맥락

- Story 4.1은 결과 요약 바와 테이블을 구현했다.
- Story 4.2는 검토 필요/완료 토글과 요약 바 갱신을 구현했다.
- Story 3.3은 `sessions.insight_summary`에 `summary`, `recommendedActions`, `topPrimaryCauses`, `cohortComparison` JSON 문자열을 저장한다.

### 이번 Story의 핵심 제약

- 노션 출력은 브라우저 전용 함수로 처리하고 서버 호출을 추가하지 않는다.
- 클립보드 복사는 HTTPS 제약이 있으므로 fallback 또는 사용자 안내가 필요하다.
- 결과 화면의 Primary 버튼은 "노션 형식 복사" 하나로 유지한다.
- 인사이트 카드는 `#F7F7F8` 배경, 8px radius 계열을 사용한다.
