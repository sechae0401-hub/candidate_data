# Story 2.3: GPT-5.5 전체 컬럼 분석 및 확인 화면

Status: review

## Story

채매니저로서,
GPT가 내 파일의 컬럼을 어떻게 이해했는지 확인하고 승인한 후에만 분류가 시작되도록 하고 싶다,
그래야 AI가 잘못된 컬럼을 기준으로 분류하는 사태를 막을 수 있다.

## Acceptance Criteria

1. **[자동 분석 시작]** 양식 검증을 통과한 파일이 있으면 GPT-5.5 컬럼 분석이 자동 실행되고 "AI가 파일을 분석하고 있습니다..." 로딩 표시가 나타난다. (FR7)
2. **[확인 화면 표시]** 분석 완료 후 각 컬럼명과 AI의 이해 내용이 표 형식으로 표시된다. (FR8)
3. **[명시적 승인]** 사용자가 "이 내용으로 진행" 버튼을 눌러야 다음 단계(취소 대상 선택 카드)가 활성화된다. (FR9)

## Dev Notes

### 이전 Story에서 이어받는 맥락

- Story 2.2에서 템플릿 검증 통과 여부가 `validationResult.status === "valid"`로 정리됐다.
- `src/lib/gpt-client.ts`는 OpenAI Responses API 래퍼를 이미 갖고 있고, 피드백 규칙상 결과 텍스트는 `output_text`에서 읽어야 한다.

### 이번 Story의 핵심 제약

- 브라우저에서 OpenAI SDK를 직접 호출하지 않는다. 서버 Route Handler를 반드시 경유한다.
- OpenAI 응답은 JSON 문자열만 오도록 프롬프트를 강하게 제한하고, 파싱 후 Zod 검증으로 한 번 더 걸러야 한다.
- 승인 전에는 다음 단계 UI를 실제로 활성화하면 안 된다.
