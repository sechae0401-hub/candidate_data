# Story 4.4: 새 분류 시작 및 반응형 레이아웃

Status: review

## Story

채매니저로서,
다음 기수 데이터를 바로 분류하러 돌아갈 수 있고, 다양한 화면 크기에서도 결과 테이블을 편리하게 볼 수 있길 원한다,
그래야 반복 업무를 끊김 없이 처리할 수 있다.

## Acceptance Criteria

1. **[새 분류 시작]** 결과 화면에서 "새 분류 시작" 버튼을 클릭하면 `localStorage`의 `session_id`와 분류 draft가 초기화되고 `/upload` 화면으로 이동한다. (FR37)
2. **[복사 후 다음 행동 강조]** 노션 형식 복사가 완료되면 성공 토스트가 표시되고 "새 분류 시작" 버튼이 시각적으로 강조된다. (FR37)
3. **[노트북 2단 레이아웃]** 1024px 이상 화면에서는 분류 결과 테이블과 원문 사이드 패널이 좌우 2단으로 나란히 표시된다. (UX-DR6, UX-DR13, NFR10)
4. **[태블릿/모바일 패널]** 1024px 미만 화면에서 행을 클릭하면 원문 패널이 하단 시트 형태로 표시된다. (UX-DR13)
5. **[터치 영역]** 결과 화면의 버튼과 클릭 가능한 행은 최소 높이 44px 이상이다. (UX-DR16)
