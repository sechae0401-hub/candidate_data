# Story 2.2: 양식 자동 검증

Status: review

## Story

채매니저로서,
파일을 업로드하면 필수 컬럼이 있는지 자동으로 확인하고, 문제가 있으면 구체적인 안내를 받고 싶다,
그래야 잘못된 파일로 분류를 시작하는 실수를 방지할 수 있다.

## Acceptance Criteria

1. **[검증 통과]** 필수 컬럼(인터뷰내용, 특이사항, 최종결과)이 모두 있으면 업로드 직후 자동 검증이 실행되고 "양식 확인 완료. AI 컬럼 분석을 시작합니다" 메시지가 표시된다. (FR4)
2. **[필수 컬럼 누락]** 필수 컬럼 중 하나가 없으면 "필수 컬럼 'XXX'이 없습니다. 분析용 양식을 먼저 다운로드해 사용해 주세요" 메시지와 양식 다운로드 버튼이 표시되고, 분류 실행 버튼은 비활성화된다. (FR5)
3. **[유사 컬럼 감지]** "인터뷰내용" 대신 "면담내용"처럼 비슷한 컬럼명이 있으면 "'인터뷰내용' 컬럼이 없습니다. '면담내용' 컬럼이 비슷합니다. 양식을 수정하거나 다시 확인해 주세요" 메시지가 표시되고 분류 실행 버튼은 비활성화된다. (FR6)
