# Story 2.4: 취소 대상 선택 및 분류 실행 트리거

Status: review

## Story

채매니저로서,
최종결과 컬럼의 값 목록에서 취소 관련 항목을 선택하면 분류 대상 건수가 실시간으로 표시되고 분류 실행 버튼이 활성화되길 원한다,
그래야 합격·보류 같은 불필요한 행을 제외하고 정확한 건수만 분류할 수 있다.

## Acceptance Criteria

1. **[체크박스 목록]** AI 컬럼 분석 승인 후 최종결과 컬럼의 값 목록이 체크박스로 표시된다. (FR10)
2. **[실시간 건수]** 취소 관련 값을 체크하면 "분류 대상 N건"이 실시간으로 갱신된다. (FR11)
3. **[기수명 입력]** 기수명 입력란이 표시되고 입력한 값은 결과 화면 상단 표시용으로 저장된다. (FR12)
4. **[분류 실행 활성화]** 취소 대상이 1건 이상 선택되면 "분류 실행" 버튼이 활성화된다. (FR13)
5. **[세션 생성 후 이동]** 버튼 클릭 시 세션을 생성하고 `localStorage.session_id`를 저장한 뒤 `/analyzing`로 이동한다.

## Dev Notes

### 이전 Story에서 이어받는 맥락

- Story 2.3까지 완료된 상태에서는 업로드 → 검증 → GPT 컬럼 분석 → 사용자 승인 흐름이 준비돼 있다.
- `WorkbookSnapshot.rows`에는 각 행이 문자열 레코드로 남아 있으므로, 최종결과 컬럼 기준 집계는 브라우저에서 바로 계산할 수 있다.

### 이번 Story의 핵심 제약

- 분류 실행은 승인 후에만 가능해야 하므로, 승인 전에는 취소 대상 선택 카드가 보이지 않거나 비활성 상태여야 한다.
- 브라우저는 Supabase에 직접 접근하지 않고 `/api/sessions`를 통해 세션을 만든다.
- 세션 ID는 이후 `/analyzing`, `/result` 가드에서 재사용하므로 `localStorage.session_id` 키를 일관되게 사용한다.
