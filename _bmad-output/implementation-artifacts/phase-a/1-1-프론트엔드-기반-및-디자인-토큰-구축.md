# Story 1.1: 프론트엔드 기반 및 디자인 토큰 구축

Status: review

## Story

개발자로서,
Next.js 14 App Router + TypeScript(엄격 모드) + Tailwind CSS + shadcn/ui + Pretendard 폰트와 디자인 토큰이 구성된 프로젝트를 갖고 싶다,
그래야 모든 UI 컴포넌트를 일관된 디자인 시스템 위에서 개발할 수 있다.

## Acceptance Criteria

1. **[빌드 성공]** Next.js 14 App Router 프로젝트가 TypeScript 엄격 모드(`"strict": true`)로 스캐폴딩되어 있다. `npm run build` 실행 시 TypeScript 에러 없이 성공한다.

2. **[색상 토큰]** Tailwind CSS에 커스텀 색상 토큰이 설정되어 있다. 컴포넌트에서 `bg-ink`, `bg-surface`, `border-hairline`, 상태 색상 클래스를 사용하면 각각 `#111827`, `#F7F7F8`, `#E5E7EB`, 완료(`#10B981`), 검토필요(`#F59E0B`), 에러(`#EF4444`)로 렌더링된다. (UX-DR2, UX-DR3)

3. **[Pretendard 폰트]** Pretendard 폰트가 설정되어 있다. 어떤 페이지를 렌더링하더라도 모든 텍스트 요소의 font-family가 Pretendard(한글+영문 통합)이다. (UX-DR1)

4. **[타이포그래피 스케일]** 타이포그래피 스케일이 Tailwind 설정에 있다. 컴포넌트에서 타이포그래피 유틸리티 클래스를 사용하면 페이지 제목 24px/600, 섹션 제목 18px/600, 본문 15px/400, 테이블 셀 14px/400, 배지 12px/500이 적용된다. (UX-DR4)

5. **[shadcn/ui 설치]** shadcn/ui 기본 컴포넌트(Button, Card, Badge, Checkbox, Progress, Toast)가 설치되어 있다. 각 컴포넌트를 import해 렌더링할 때 컴파일 에러 없이 화면에 표시된다.

## Dev Notes

### 핵심 제약사항

- **브라우저 전용 처리**: SheetJS(엑셀 파싱)와 노션 출력(클립보드 복사)은 브라우저에서만 처리. 서버 API에서 import 금지. 이 story에서는 설치하지 않음 (Epic 2에서 추가).
- **server-only 패키지**: `src/shared/supabase/server.ts`는 Story 1.2에서 생성. 이 story에서는 Supabase 관련 파일 생성 금지.
- **환경변수**: Story 1.1에서는 `.env.local` 불필요. 환경변수는 Story 1.2에서 설정.
- **인증 없음**: v1은 채매니저 단독 사용 — 로그인/인증 코드 작성 금지.
- **Edge Runtime 금지**: Vercel Edge Runtime 사용 금지 (Supabase SSR 호환 문제, [Source: docs/agents/performance-rules.md]).
