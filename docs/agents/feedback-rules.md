## 규칙 추가 방법

1. 실수/사고 발생 시 `feedback/incidents/` 아래에 파일 생성
2. 패턴이 반복되면 이 파일의 Active Rules에 추가
3. 10개 초과 시 가장 오래된 것부터 Archived로 이동
