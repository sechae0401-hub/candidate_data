## 0. 한눈에 보기 (내부 공유용)

**한 줄 정의**: 교육과정 취소자 엑셀을 제공된 양식에 맞춰 업로드하면, GPT-5.5가 전체 컬럼을 자동 분석하고 취소 사유를 분류해주는 사내 분석 도구

**핵심 문제**: 인터뷰·메모를 건당 직접 읽고 분류하는 데 기수당 2~3시간이 걸리고, 키워드 분류는 복합 원인을 하나로 잘라버려 데이터 정확도가 낮음

**우리 해결책**: 고정된 엑셀 양식을 제공하고, 양식에 맞게 업로드하면 GPT-5.5가 전체 컬럼을 자동으로 파악해 취소 사유(1차 원인·2차 행동·세부 태그·판단 근거)를 일괄 분류. 검토가 필요한 건만 사람이 확인

**차별점**: 엑셀 컬럼을 손으로 지정할 필요 없이 AI가 전체를 읽고 스스로 이해. 사용자는 AI가 파악한 내용을 한 번 확인하고 승인하면 바로 분류 시작

**1단계 범위 (4주 이내 완성 목표)**:
① 분석용 엑셀 양식 다운로드
② 엑셀 업로드 + 양식 자동 검증
③ AI 전체 컬럼 분석 + 사용자 확인 화면
④ 분석할 취소 대상 선택
⑤ AI 취소 사유 분류 (3건씩, 1차 원인·2차 행동·세부 태그·판단 근거·검토 필요 여부)
⑥ 분류 결과 테이블 + 인라인 수정 + 노션 형식 복사
⑦ 인사이트 한 단락 요약
⑧ 신규 카테고리 자동 생성

**기대 효과**: 기수당 분석 시간 2~3시간 → 15분 이내 / 컬럼 설정 시간 0분 (AI가 자동 처리)

**비용**: OpenAI GPT-5.5 API 요금 기수당 $0.50 이하 추정. 인프라 월 $0 (Vercel + Supabase 무료 플랜)

## 1. 한 문장 서비스 정의

> 교육과정 운영 담당자가 분석용 엑셀 양식에 맞춰 취소자 데이터를 업로드하면, GPT-5.5가 전체 컬럼을 자동으로 이해하고 인터뷰·특이사항을 맥락으로 읽어 취소 사유를 기본 6개 항목(1차 원인·2차 행동·세부 태그·타 과정명·판단 근거·검토 필요)과 신규 카테고리로 분류하는 사내 분석 도구.

## 2. 누가 쓰는가

### 2.1 1순위 사용자
- **누구**: 아이티커넥트 마케팅/홍보 부서 운영 담당자 (현재 대표 본인)
- **상황**: 기수 종료 후 취소자 데이터를 받아 다음 기수 모집 전략을 수정해야 하는 반복 업무
- **현재 방식**: 엑셀 열어 키워드 필터 → 애매한 건 직접 읽고 수동 분류 → 취소 사유 집계 → 전략 반영

### 2.2 2순위 사용자 (추후)
- **누구**: 팀원 (모집 담당자)
- **상황**: 대표가 분류·정리한 결과를 공유받아 다음 모집 공고·인터뷰 프로세스 개선에 활용
- **1단계 공유 방식**: 노션 형식으로 복사한 분류 결과 문서를 팀 노션에 붙여넣어 공유

## 3. 현재 문제

인터뷰 내용과 특이사항에는 복합 맥락이 담겨 있다.

예시: "내일배움카드 발급이 늦어져 타 과정을 신청하려고 함"
- 키워드 분류 결과: "내일배움카드" 또는 "타 과정 이동" 중 하나만 잡힘
- 실제 필요한 분류: 1차 원인(내일배움카드 이슈) + 2차 행동(타 과정 신청) 동시 추출

이 복합 사유를 사람이 하나하나 읽고 판단하는 데 1기수당 2~3시간 소요.
담당자마다 분류 기준이 달라 기수 간 데이터 비교도 어렵다.

또한 엑셀 컬럼 구성이 기수마다 조금씩 달라, 기존 도구에서는 매번 컬럼을 손으로 지정해야 했다.

| 기존 방법 | 한계 |
|---|---|
| 엑셀 키워드 필터 + 찾기 | 복합 원인을 하나로 잘라버림. 판단 근거 없음 |
| 담당자 직접 수동 분류 | 건당 시간 소요. 기준이 사람마다 달라 기수 간 비교 불가 |

---

## 4. 핵심 가치

**Before**: 엑셀을 열어 한 줄씩 읽으며 머릿속으로 분류. 컬럼도 매번 손으로 지정. 기수당 2~3시간.

**After**: 제공된 양식에 취소자 데이터를 붙여넣고 업로드. AI가 컬럼을 자동으로 파악하고 전체 취소 사유를 분류. 결과 확인 및 검토 필요 건만 수정. 15분 이내 완료.

**핵심 변화**: "기수마다 컬럼 설정하고 2~3시간 분류하던 일을, 양식 업로드 하나로 15분 안에 끝낸다."

## 5. 대표 사용 시나리오

### 시나리오 1: 기수 종료 후 취소자 일괄 분류

- **상황**: 기수가 끝나고 운영팀에서 취소자 데이터를 전달받은 직후
- **흐름**: 도구에서 분석용 엑셀 양식을 다운로드 → 취소자 데이터를 양식에 붙여넣어 저장 → 도구에 업로드 → AI가 양식을 검증하고 컬럼을 자동 파악 → "AI가 이렇게 이해했습니다" 확인 화면에서 승인 → 취소 대상 체크박스 선택 → 분류 실행 → 검토 필요 건만 확인 → 노션 형식 복사
- **결과**: 15분 내 완료. 컬럼 설정 없음. 팀 노션에 바로 붙여넣기 가능

### 시나리오 2: 검토 필요 건 빠르게 처리

- **상황**: 분류가 완료됐는데 "검토 필요" 표시가 12건
- **흐름**: 결과 테이블에서 노란색으로 표시된 12건 클릭 → 원문 사이드 패널에서 인터뷰 내용 확인 → 1차 원인·2차 행동 인라인 수정 → 검토 완료 표시 → 초록색으로 전환 → 모두 완료 시 노션 복사 버튼 활성화
- **결과**: 검토 필요 건만 골라 빠르게 처리. 전체 재분류 불필요

### 시나리오 3: 다음 기수 분석 (동일 양식 재사용)

- **상황**: 다음 기수 데이터가 도착
- **흐름**: 동일한 양식에 새 데이터 붙여넣어 업로드 → AI가 동일 양식 확인 → 바로 취소 대상 선택 → 분류 실행
- **결과**: 컬럼 설정 없이 바로 시작. 이전 기수와 동일한 기준으로 분류

## 6. 1단계 범위 확정

### 6.1 포함 기능

| 기능 그룹 | 세부 기능 | 포함 이유 |
|---|---|---|
| 양식 관리 | 분석용 엑셀 양식 다운로드 | 컬럼 설정 없이 표준화된 데이터 입력을 위한 전제 |
| 파일 업로드 | 엑셀 파일 업로드, 파일 형식 검증 | 도구 사용의 첫 단계 |
| 양식 검증 | 필수 컬럼 존재 확인, 컬럼명 변경 안내 | 잘못된 파일 업로드 시 분석 실행 전에 안내 |
| AI 컬럼 분석 | 전체 컬럼 자동 파악, 분석 결과 확인 화면 | 컬럼 수동 지정 없이 AI가 자동 처리 |
| 취소 대상 선택 | 최종결과 값 기준 체크박스 선택, 건수 표시 | 합격자·보류 등 분류 불필요 행 자동 제외 |
| AI 분류 | 3건씩 나누어 분류, 1차 원인·2차 행동·세부 태그·판단 근거·검토 필요, 신규 카테고리 자동 생성 | 핵심 가치 |
| 오류 처리 | 정보 부족 행 자동 처리, 일부 실패 시 검토 필요 처리 후 계속, 전체 실패 시 재시도 | 분류 중단 없이 진행 |
| 결과 관리 | 결과 테이블, 검토 필요 행 색상 표시, 원문 사이드 패널, 인라인 수정, 자동 저장, 검토 완료 처리 | 검토 1회로 마무리 |
| 출력 | 노션 형식 결과 복사, 인사이트 한 단락 요약, 신규 카테고리 목록 표시 | 팀 공유 바로 가능 |
| 진행 안전 | 분류 중 이탈 경고 | 실수로 화면 이탈 시 분류 중단 방지 |

### 6.2 제외 범위 및 이동 단계

| 기능 | 단계 | 이유 |
|---|---|---|
| 대시보드 3뷰 (전체·유입경로별·진행 단계별) | 2단계 | 1단계 핵심(분류·검토·출력)이 안정화된 후 추가 |

| CSV 다운로드 | 2단계 | 노션 형식으로 대체 |
| n8n·Make 등 외부 자동화 연동 | 제외 | 서비스 안에서 직접 처리 |

## 8. 주요 위험과 대응

| 위험 | 영향 | 대응 |
|---|---|---|
| AI가 컬럼을 잘못 파악 | 분류 결과 오류 | 확인 화면에서 사용자가 검토 후 승인 |

| GPT-5.5 응답 오류 | 일부 건 분류 실패 | 해당 건만 검토 필요 처리 후 나머지 계속 진행 |
