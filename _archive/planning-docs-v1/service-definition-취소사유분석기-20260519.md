## 0. Executive Summary (1페이저 — 내부 공유용)

**한 줄 정의**: 교육과정 취소자 엑셀 데이터를 업로드하면 GPT-4o가 인터뷰·특이사항을 맥락으로 읽고 취소 사유를 기본 6개 항목+신규 카테고리 자동 생성으로 분류하며, 전체·유입경로별·진행 단계별 3뷰 대시보드와 노션 형식 문서를 함께 제공하는 사내 분석 도구

**핵심 문제**: 인터뷰·메모를 건당 직접 읽어 분류해야 해서 시간이 오래 걸리고, 키워드 분류는 다중 원인을 하나로 잘라버려 데이터가 틀림

**우리 해결책**: GPT-4o API가 맥락 전체를 읽고 1차 원인·2차 행동·판단 근거를 동시에 추출, 검토 필요 항목만 사람이 확인

**차별점**: 키워드 필터로 불가능한 "맥락 기반 다중 원인 분리 분류" + 유입경로별·진행 단계별 취소 패턴 교차 분석까지 한 번에 제공

**2~4주 MVP 범위**: ① 엑셀 업로드+컬럼 매핑 ② GPT-4o 분류(기본 6항목+신규 카테고리 자동 생성) ③ 분류 결과 테이블 + 노션 붙여넣기 형식 출력 ④ 요약 대시보드 3뷰(전체·유입경로별·진행 단계별)+토큰 접근 제어 ⑤ 검토 필요 목록 ⑥ 신규 카테고리 누적 목록

**기대 효과 (정량)**: 1기수 취소자 분석 시간 추정 2~3시간 → 15분 이내 / 분류 오류율 현저 감소 (키워드 오분류 → AI 맥락 분류로 대체)

**필요 자원**: 1인 / 2~4주 / OpenAI GPT-4o API 사용료 (추정 기수당 $2~5 수준)

## 1. 한 문장 서비스 정의

> 교육과정 마케팅·모집 담당자가 취소자 인터뷰·특이사항 메모가 담긴 엑셀을 업로드하면, GPT-4o API가 맥락을 읽고 취소 사유를 기본 6개 항목(1차 원인·2차 행동·세부 태그·타 과정명·판단 근거·검토 필요) 기준으로 자동 분류하되, 기존 항목으로 설명되지 않는 사유는 신규 카테고리를 자동 생성하여 분류하는 사내 분석 도구.

## 2. 타깃 고객

### 2.1 1순위 타깃
- **누구**: 아이티커넥트 마케팅/홍보 부서 운영 담당자 (현재 주로 대표 본인)
- **상황**: 기수 종료 후 취소자 데이터 엑셀을 받아 다음 기수 모집 전략을 수정해야 하는 반복 업무 주기가 있음
- **현재 행동**: 엑셀 다운로드 → 키워드 필터로 1차 분류 → 애매한 건 직접 읽고 수동 분류 → 취소 사유 집계 → 전략 반영

### 2.2 2순위 타깃 (추후 가능)
- **누구**: 팀원 (모집 담당자)
- **상황**: 대표가 분석한 결과를 공유받아 다음 모집 공고·인터뷰 프로세스 개선에 활용
- **현재 행동**: 구두 보고 또는 메신저로 결과 공유 받음

## 3. 현재 문제와 기존 대안

### 3.1 문제 정의

인터뷰 내용과 특이사항에는 복합 맥락이 담겨 있다.  
예: "내일배움카드 발급이 늦어져 타 과정을 신청하려고 함"  
→ 키워드 분류 결과: "내일배움카드" 또는 "타 과정 이동" 중 하나만 잡힘  
→ 실제 필요한 분류: 1차 원인(내일배움카드 이슈) + 2차 행동(타 과정 신청) 동시 추출

이 복합 사유를 사람이 하나하나 읽고 판단하는 데 1기수당 수 시간이 소요되며,  
담당자마다 분류 기준이 달라 기수 간 데이터 비교가 어렵다.

### 3.2 기존 대안

| 대안 | 한계 |
|---|---|
| 엑셀 키워드 필터 + 찾기 | 복합 원인을 하나로 잘라버림. 판단 근거 없음. 애매한 건 결국 수동 확인 |
| 담당자 직접 수동 분류 | 건당 시간 소요. 담당자마다 기준 달라 기수 간 데이터 비교 불가 |

## 4. 핵심 가치 제안

**Before** (이 도구 없을 때):  
엑셀을 열어 인터뷰 내용을 한 줄씩 읽으며 머릿속으로 분류. 1기수 수십 명 기준 2~3시간 소요. "내일배움카드 이슈인지 타 과정 이탈인지" 같은 복합 사유는 하나로만 기록되어 데이터 손실.

**After** (이 도구 사용 후):  
엑셀 업로드 → GPT-4o가 인터뷰 전체 맥락 읽기 → 기본 6개 항목 분류 + 미분류 사유는 신규 카테고리 자동 생성 → 15분 내 전체 분류 완료. 결과는 요약 대시보드(토큰 링크로 권한자만 접근)와 노션 붙여넣기 형식 문서 두 가지로 출력. 검토 필요 항목만 수동 확인.

**핵심 변화 한 문장**:  
"기수 종료 후 2~3시간 걸리던 취소 사유 분석을 15분 안에 끝내고, 팀에 데이터 기반으로 공유한다."

## 5. 대표 사용 시나리오 (3개)

### 시나리오 1: 기수 종료 후 취소자 일괄 분석

- **상황**: 교육과정 기수가 끝나고 운영팀에서 신청·취소 데이터 엑셀을 전달받은 직후
- **행동**: 엑셀을 이 도구에 업로드 → 컬럼 확인(인터뷰 내용, 특이사항, 신청 상태, 유입경로, 진행 단계) → AI 분류 실행 → "검토 필요" 표시된 5~10건만 직접 확인 → 분류 결과 테이블 확인 + 노션 붙여넣기 형식 문서 복사
- **결과**: 15분 내 전체 취소자 분류 완료. 테이블로 전체 데이터 검토 후 노션에 붙여넣어 팀 문서화까지 한 번에 해결

### 시나리오 2: 취소 사유 TOP5 확인 후 다음 기수 전략 수정

- **상황**: 이번 기수 취소율이 지난 기수보다 높아져 원인 파악이 필요한 상황
- **행동**: 요약 대시보드 → 취소 사유 TOP5 확인 → "내일배움카드 이슈" 급증 발견 → 다음 기수 모집 공고에 카드 발급 소요 기간 안내 문구 추가
- **결과**: 데이터 근거 있는 전략 수정. 구두 감으로 수정하던 방식 탈피

### 시나리오 3: 팀원과 분석 결과 공유

- **상황**: 모집 담당 팀원에게 이번 기수 취소 패턴을 설명해야 하는 주간 미팅
- **행동**: 토큰이 포함된 대시보드 URL을 팀원에게 공유 (토큰 없는 URL로는 접근 불가) → "타 과정 언급 현황"과 "후속 행동 분포" 화면 함께 확인
- **결과**: 구두 보고 대신 데이터 기반 공유. 권한자 외 외부 유출 없이 팀 내 안전하게 공유

## 6. MVP 범위

### 6.1 포함 기능 (필수, 6개)

| # | 기능 | 왜 MVP에 필수인가 |
|---|---|---|
| 1 | 엑셀 업로드 + 컬럼 매핑 | 도구 사용의 첫 단계. 유입경로·진행 단계 컬럼도 매핑 대상에 포함. 컬럼이 없으면 수동 지정으로 대체 |
| 2 | GPT-4o 맥락 기반 분류 (기본 6개 항목 + 신규 카테고리 자동 생성) | 핵심 가치. 기본 항목(1차 원인·2차 행동·세부 태그·타 과정명·판단 근거·검토 필요)으로 설명 안 되는 사유는 AI가 신규 카테고리명을 생성해 자동 분류 |
| 3 | 분류 결과 테이블 + 노션 붙여넣기 형식 문서 출력 | 테이블: 전체 데이터 한눈에 확인·수정. 노션 형식: 마크다운으로 복사 후 팀 문서에 바로 붙여넣기. 두 형식 병행 제공 |
| 4 | 요약 대시보드 3뷰 + 토큰 기반 접근 제어 | **전체 뷰**(기본), **유입경로별 뷰**, **진행 단계별 뷰**(인터뷰 전·후 등)로 탭 전환. 토큰(접근 키)이 포함된 URL을 가진 사람만 열람 가능 |
| 5 | 검토 필요 항목 별도 목록 | AI가 판단 불확실로 표시한 항목만 모아 빠르게 수동 확인할 수 있도록 분리 표시 |
| 6 | 신규 카테고리 누적 목록 | 자동 생성된 신규 카테고리명을 별도 목록으로 보여줌. 반복 등장 시 표준 항목으로 승격 여부 판단 가능 |

### 6.2 제외 범위 (v1에서 안 함)

- **CSV 다운로드**: 노션 붙여넣기 형식으로 대체. 엑셀 워크플로우 연결이 필요해지면 v2에서 추가
- **회원가입·로그인 시스템**: 토큰 기반 접근 제어로 대체. 팀별 계정 관리가 필요해지면 v2에서 추가
- **기수별 히스토리 누적 및 기수 간 비교**: 데이터 저장 구조가 복잡해져 MVP 기간 초과. v2에서 추가
- **분류 기준 커스터마이징 UI**: 기본 6개 항목 정의를 사용자가 직접 수정하는 화면. 프롬프트 수정으로 대체. v2에서 추가
- **다음 기수 전략 자동 제안**: 분석 → 제안까지 자동화. 검증 전 추가하면 신뢰도 리스크. v3 이후
